# 二维码识别 Chrome 扩展

右键点击网页上的图片或 canvas，识别二维码内容。如果是链接，可以点击跳转；如果是文本，直接弹窗展示。

## 功能特色

- ✅ **支持普通图片二维码** (`<img>` 标签) - 右键直接识别
- ✅ **支持 Canvas 二维码** - 很多网页用 canvas 渲染二维码，也能完美识别
- ✅ **识别失败轻提示** - 非二维码图片显示「未能识别到二维码」，2秒自动消失
- ✅ **链接手动跳转** - 识别到链接后弹窗展示，点击按钮才跳转，更安全可控
- ✅ **文本直接展示** - 非链接二维码内容直接弹窗显示
- ✅ **支持跨域图片** - 自动处理跨域问题
- ✅ **ESC 取消操作** - 随时按 ESC 取消识别

## 安装方法

1. 下载本项目文件夹到本地
2. 打开 Chrome 浏览器，地址栏输入 `chrome://extensions/`
3. 打开右上角的 **开发者模式** 开关
4. 点击 **加载已解压的扩展程序**
5. 选择本项目文件夹 `qr-image-scanner`
6. 点击扩展详情，打开 **允许访问文件网址**（识别本地HTML文件中的二维码需要这个权限）

完成安装！

## 使用方法

### 场景 1：图片二维码（`<img>` 标签）

直接在二维码图片上**右键点击** → 选择「识别二维码并跳转」→ 识别完成后弹窗显示结果。如果是链接，点击「打开链接」按钮跳转。

### 场景 2：Canvas 二维码

在二维码附近任意位置**右键点击** → 选择「识别二维码并跳转」→ 页面变暗，提示「点击二维码」→ 点击 canvas 上的二维码 → 识别完成弹窗显示。

### 场景 3：取消操作

进入选择模式后，按 `ESC` 键可以取消识别。

## 项目结构

```
qr-image-scanner/
├── manifest.json    # Chrome 扩展配置（Manifest V3）
├── background.js    # 后台脚本 + 识别逻辑（带详细注释）
├── jsQR.js          # 二维码识别库（jsQR v1.4.0）
└── README.md        # 本文档
```

## 技术说明

- 使用 [jsQR](https://github.com/cozmo/jsQR) 开源二维码识别库
- 基于 Chrome 扩展 Manifest V3 开发
- 动态注入脚本，点击才加载，不影响网页性能
- 自动处理跨域问题，兼容大多数网站

## 权限说明

- `contextMenus` - 创建右键菜单
- `scripting` - 注入识别脚本到网页
- `host_permissions` - 允许在所有网页上运行
